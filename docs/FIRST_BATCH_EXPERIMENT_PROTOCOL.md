# BoilerMind 第一批种子实验协议

## 目标

在当前统一执行器的真实能力边界内，建立 M@40 模型基准、多随机种子稳定性、工况分层和独立审计记录。

## 冻结口径

- 数据：`resources/data/shortperiod_new.csv`
- 数据身份：运行前计算 SHA-256，并写入每个实验契约与 manifest
- 目标：`main_steam_mass_flow`
- 输入：30 个已注册特征
- 采样：15 秒
- 历史窗口：20 步（5 分钟）
- 预测跨度：40 步（10 分钟）
- 切分：按时间 70%/15%/15%
- 模型选择：仅使用 validation
- locked test：只用于冻结后的最终评价
- 指标：MAE、RMSE、R2、MBE
- 参考模型：Persistence
- 设备：CPU

## BM-SEED-01 统一模型基准

候选模型为当前能力注册表中的 14 个真实可执行模型。每个模型在独立进程和独立实验目录中运行，防止高成本模型超时或内存失败影响其他模型。任何 warning、失败原因、运行时间和未收敛状态必须保留。

### 假设

- H-SEED-01A：复杂模型不会普遍稳定优于 Persistence。
- H-SEED-01B：validation 排名与 locked-test 排名可能发生变化。
- H-SEED-01C：模型优势可能因 MAE、RMSE、R2、MBE 指标不同而改变。

### 首轮 seed

首轮统一使用 seed=42。完成后根据结果选择代表模型进入 BM-SEED-02，使用 `[7, 19, 42, 5, 23, 11]`。

## 超时与失败

- 外部调度器对每个模型施加独立超时。
- 超时、内存不足、依赖错误、未收敛属于工程观察，不属于科学证伪。
- 不允许使用其他模型结果替代失败模型。
- 不允许从候选集合中静默删除失败模型。

## 后续

- BM-SEED-02：多 seed 稳定性。
- BM-REGIME-01：复用 locked-test 预测，按统一工况分层。
- 独立审计：数据身份、时间索引、泄漏、指标方向、样本一致性和失败保留。
